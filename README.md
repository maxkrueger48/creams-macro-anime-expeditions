## Project Summary

Serving as a lightweight web front-end for the Anime Expeditions macro, Cream's Macro offers a centralized portal to check project updates, grab compiled assets, consult guides, and watch an embedded YouTube walkthrough. The architecture requires no backend infrastructure.

Constructed entirely with standard HTML, CSS, and plain JavaScript, the portal mimics native application layouts and features real-time aesthetic theme toggling. By pulling live release counts and build information directly via the GitHub API, the client maintains synchronization with published binaries while remaining fully hostable on static platforms like GitHub Pages.
